# 01 · 总路线图

> 这张图回答一个问题：**从零基础到做出「图书管理系统」，一共要走几步、每步花多少小时、什么时候才可以往下走。**

先在第一张图里找到自己的位置，再用第二张图决定「要学多深」，最后照第三张图的循环去执行每一天。

## 二、三条路径对比 · 先选路径再开始

```mermaid
flowchart LR
    Q{"你的目标是什么?"}
    Q -- "只为交课程设计 / 作业" --> P1
    Q -- "想真正学会全栈开发" --> P2
    Q -- "准备找开发工作" --> P3

    P1["🏃 <b>速通版</b><br/>约 260 h<br/>砍掉 Python 面向对象进阶<br/>SQL 索引原理 / TypeScript / React 进阶"]
    P2["🚶 <b>标准版</b> · 推荐<br/>约 470 h<br/>阶段 0 → 7 完整走完<br/>4 个关卡 + 回炉机制全保留"]
    P3["🧗 <b>完整版</b><br/>约 515 h<br/>标准版 + 阶段 8<br/>Docker / 测试 / 压测 / 部署"]

    P1 --> R1["产出：能演示的系统<br/>但讲不清并发与事务"]
    P2 --> R2["产出：能讲清行锁与隔离级别<br/>可以写进简历"]
    P3 --> R3["产出：可部署上线 + 工程化<br/>面试能讲满 10 分钟"]

    style P2 fill:#2d6a4f,color:#fff
    style P3 fill:#1d3557,color:#fff
    style R3 fill:#f4a261,color:#000
```

| 路径 | 工时 | 砍掉了什么 | 适合谁 | 风险 |
|---|:---:|---|---|---|
| 🏃 速通版 | ~260 h | Python 面向对象进阶、SQL 索引原理、TypeScript、React 进阶 | 只为交课程设计，能跑就行 | 被问「并发怎么办」会答不上来 |
| 🚶 标准版（推荐） | ~470 h | 什么都不砍，按顺序走完 0–7 | 想真正学会全栈开发 | 周期长，中途容易放弃 |
| 🧗 完整版 | ~515 h | 标准版 + 阶段 8 | 准备找开发工作 | 前面没吃透就上 Docker，收益很低 |

**换算成日历时间（按核心 470 h 算）：** 每天 1 h ≈ 16 个月 · 每天 2 h ≈ 8 个月 · 每天 3 h ≈ 5 个月 · 每天 6 h ≈ 3 个月。

> 💡 **新手最大的误区是一上来就选完整版。** 先用速通版跑到「能演示」，再回来补 TypeScript 和并发，动力会强得多。

## 三、学习循环 · 每个阶段都照这个跑

```mermaid
flowchart LR
    A["① 看资源<br/>官方文档 / 视频"] --> B["② 关上资料<br/>自己敲一遍"]
    B --> C["③ 做阶段练习<br/>不抄答案"]
    C --> D{"④ 对照验收标准自测<br/>能演示给别人看吗?"}
    D -- "✅ 通过" --> E["⑤ 打勾 · 更新 progress.md<br/>进入下一阶段"]
    D -- "❌ 不通过" --> F["⑥ 定位到具体知识点<br/>只重学那一小节"]
    F --> B

    style D fill:#fff3cd,color:#000
    style E fill:#2d6a4f,color:#fff
    style F fill:#f8d7da,color:#000
```

**三条铁律：**

1. **不许只看不敲。** 视频看 1 小时，必须配 1 小时自己写代码。看视频产生的「我懂了」是假的。
2. **不许抄答案。** 卡住先查官方文档，超过 30 分钟再看参考实现。
3. **不许跳关。** 阶段 3（数据库）和阶段 6B（JavaScript 进阶）跳过去，后面必崩。

**一周的节奏：** 周一/周二看资源并跟着敲 → 周三/周四脱离资料重写 → 周五/周六做练习 → 周日跑验收，过了打勾，不过就定点回炉。回炉不是失败，是标准动作。
